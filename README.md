# bible_wonders

Flutter app for **Wonders and Hope** — the Bible's miracles, with the passage
open beside you.

This project lives on its own under Mobile Development. It does not depend on
the website repo at runtime.

## Run

```bash
flutter pub get
flutter run
```

Requires Flutter 3.27+ (Dart 3.6+). See [SETUP.md](SETUP.md) for architecture,
read-aloud native setup, and how to refresh `assets/` from the website catalog.
